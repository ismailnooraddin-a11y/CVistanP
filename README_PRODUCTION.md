# Hollywood Smile Studio - Production Frontend Package

This package is a rebuilt static website for Hollywood Smile Studio Erbil.

## Included
- Luxury landing page with premium visual direction.
- WhatsApp-first booking drawer and validated contact form.
- Service detail pages for local SEO.
- Doctor profile pages using available verified data.
- Legal pages: Privacy Policy, Terms, Medical Disclaimer.
- 404 page, robots.txt, sitemap.xml, manifest and security header examples.
- WebP doctor images while keeping original PNG files.
- Frontend enhancements: glass header, hero reveal, scroll reveal, animated counters, FAQ accordion, service card glow, magnetic CTA, doctor filters, mobile sticky booking CTA, copy-phone interaction and reduced-motion support.
