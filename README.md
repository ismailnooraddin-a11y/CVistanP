# Hollywood Smile Studio Erbil

Production-ready static frontend package for a premium dental clinic website.

## Highlights
- Luxury homepage design with conversion-focused WhatsApp booking.
- Service pages for cosmetic dentistry, implants, orthodontics, endodontics, restorative care, whitening, smile design and emergency dental care.
- Doctor profile pages using available verified public data.
- Legal pages, sitemap, robots, manifest, security header examples and 404 page.
- Optimized WebP doctor images with original PNGs preserved.

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Before public launch
- Confirm final domain.
- Confirm opening hours.
- Confirm all doctor credentials, licenses, languages and schedules.
- Add only real Google reviews and patient cases with written consent.
- Deploy on HTTPS with analytics, Search Console and security headers.
