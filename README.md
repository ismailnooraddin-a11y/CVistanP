# EstateFlow CRM Frontend

A deployable, responsive frontend prototype for a small-to-medium real estate agency management platform.

## Included modules

- Executive dashboard
- Lead pipeline and lead profiles
- Client records
- Property listings and details
- Property map
- WhatsApp-style unified inbox
- Calendar, viewings, and tasks
- Contracts
- Finance and commissions
- Reports and team performance
- Subscription packages and module controls
- Company settings and integrations
- Responsive navigation and dark mode

## Deploy on Vercel

1. Extract this ZIP.
2. Upload all files to the root of a new GitHub repository.
3. In Vercel, choose **Add New > Project**.
4. Import the GitHub repository.
5. Leave **Framework Preset** as `Other`.
6. Leave the build command and output directory empty.
7. Click **Deploy**.

The app is a static frontend and requires no environment variables.

## Important scope note

This repository is a functional frontend prototype with interactive demo data. It does not yet include a production backend, persistent cloud database, real authentication, WhatsApp Cloud API, payment gateway, maps API, or AI API. Those require a later backend phase.
