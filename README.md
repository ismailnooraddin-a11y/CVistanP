# EstateFlow ERP Frontend v3

Frontend-only Next.js project prepared for GitHub and Vercel. It uses mock in-memory data; changes reset after refresh.

## Included
- Contacts, Properties, Deals, Meetings and Tasks
- Organization and HR demo modules
- Deal drag-and-drop plus back/forward stage controls
- Deal range and closing-date validation
- Reserved-property hover details
- Meeting time/location controls, edit and cancellation
- Teams-style tasks with assignment, priority and status
- System-safe font stack and UTF-8 Next.js output

## Deploy
1. Upload the contents of this folder to the GitHub repository root.
2. In Vercel select Framework Preset: Next.js.
3. Leave Output Directory on default/blank.
4. Redeploy.

Supabase, authentication, permanent storage and WhatsApp delivery are intentionally not connected yet.
