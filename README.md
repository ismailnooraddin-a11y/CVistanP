# HollyWoodSmile Studio Website

Production-ready static website for HollyWoodSmile Studio, Erbil.

## What is included

- Responsive one-page website
- Dark-blue premium medical design
- Mobile-first layout
- Doctor cards with 3D hover/tap behavior
- Doctor profile modal
- Doctor-specific WhatsApp routing
- Appointment form with selected-doctor prefill
- Generated English "Number One" poster
- Cleaning teeth video section
- Location section with Google Maps link
- Instagram and Facebook links
- XX placeholders for missing doctor details and reviews

## Deployment

Upload all files in this folder to GitHub Pages, Netlify, Vercel, or your hosting provider.

Main entry file:

```text
index.html
```

## Update doctor data

Doctor information is stored in:

```text
script.js
```

Update each doctor's:

- name
- degree
- specialty
- phone
- image
- instagram

WhatsApp numbers must use international format without `+`, for example:

```text
9647501457000
```

## Replace placeholders before launch

Search for `XX` in `index.html` and `script.js` and replace missing details when the clinic provides final information.
